# YouTube UI Clone 🎬

A pixel-perfect clone of YouTube's user interface built with pure HTML and CSS.

## Preview
![YouTube UI Clone](https://github.com/user-attachments/assets/62b40766-fa9c-4650-817a-062c37e0fd60)

## Features
- YouTube Home Page Layout ✅
- Responsive Navigation Bar ✅
- Video Cards Grid Layout ✅
- Sidebar Menu ✅
- Pure HTML & CSS (No Framework) ✅

## Built With
- HTML5
- CSS3
- Flexbox & Grid Layout

## How to Run
1. Clone the repo
   git clone https://github.com/arunengineer-rgb/youtube-ui-clone.git

2. Open index.html in your browser
   Just double click index.html ✅
